Synthèse du projet
Point fort

Pipeline TP13 industriel et exécuté

nutriscope/pipeline.py : 5 étapes orchestrées (charger, nettoyer, charger_base, parquet, exports), journal JSON, SHA-256 sur les exports. Exécuté sur 1 273 567 lignes le 15/10/2026 : 1 273 539 produits conservés, 25 490 anomalies résolues à zéro. Architecture documentée avec 5 magasins de données et règles explicites.

Point fort

Assistant LLM avec outil outillé (TP18)

Prototype completé : outil chercher_produit (nom/code, retour statut ok/ambigu/introuvable), boucle outillée anti-boucle infinie, garde-fous (jamais d'eval, refus conseil médical, valeur manquante → null). Essais réels sur vrai modèle documentés. ADR modèle attendue. Clément n'a pas ce livrable.

Infrastructure données

5 magasins de données articulés

Brut OFF → France extrait → Nettoyé → PostgreSQL (application) + Parquet analytique partitionné par rayon (DuckDB) + Export features figé (ML). Contrôles qualité sur Parquet (controle.md 2026-10-20). Export daté + schéma JSON + SHA-256 pour reproductibilité ML.

Données

EDA + statistiques poussées

8 findings EDA (Cramér V 0,34, Spearman sur 6 nutriments, Cohen's d, Mann-Whitney, paradoxe Simpson), hypothèses H1–H4 testées par rayon. Rapport nettoyage réel. 10 figures. Datastorytelling TP11 livré (PDF + PPTX). src/validation/checks.py pour les contrôles avant chargement.
